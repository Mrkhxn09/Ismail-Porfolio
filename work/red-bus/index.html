04 — APP REDESIGN UI EXERCISE

RedBus — App UI Redesign

A hands-on mobile UI exercise recreating and refining a real-world booking interface with focus on cleaner hierarchy and usability.

ROLE UI/UX Designer
CATEGORY UI/UX Design
TIMELINE 4–5 Days
TOOLS Figma
00 — HERO PREVIEW Click to inspect high-resolution screen
PROJECT OVERVIEW

This RedBus Redesign was a personal UI exercise project wherein I remade the interface to hone my design execution. Attention was paid to enhancing structure, visual hierarchy, and general consistency across multiple interconnected screens.

01 // DISCOVERY & SEARCH FLOW

Route Search & Operator Listings

Streamlined date picker, route selector, and bus operator cards with departure filters.

01 — ROUTE SEARCH Origin, destination, and departure date selection
02 — OPERATOR LISTINGS Bus operator list with timing, fare and rating tags
02 // BOOKING & SEAT SELECTION

Seat Grid & Boarding Points

Ergonomic seat selection layout with clear berth indicators and pickup location mapping.

03 — SEAT SELECTION Upper / lower deck layout with price tiers
04 — BOARDING POINTS Pickup and dropping points selection
03 // PASSENGER DETAILS & CHECKOUT

Passenger Information & Confirmation

Frictionless passenger form and instant digital ticket confirmation screen.

05 — PASSENGER DETAILS Contact info, seat allocation, and payment breakdown
06 — TICKET CONFIRMATION Digital ticket confirmation with QR code pass
04 // KEY LEARNINGS

Execution & Detail Orientation

“Every pixel I recreated brought me a step closer to mastering real-world design execution.” By reconstructing this actual-world UI, I honed my detail orientation, refined layout competency, and learned more about preserving hierarchy across multi-screen booking flows.
