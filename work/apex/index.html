02 — UI/UX & TERMINAL CONCEPT PROJECT

Apex Pro Trading Terminal

A high-density web trading terminal designed for active crypto and multi-asset traders, balancing massive real-time data depth with eye-strain reduction.

ROLE UI/UX Designer
TIMELINE 3 Weeks
DISCIPLINE High-Density UI/UX
TOOLS Figma, Vector Grid
01 // THE PROBLEM

Information Density vs. Cognitive Fatigue in Financial Terminals

Active trading platforms must display hundreds of simultaneous data points—candlestick charts, depth ladders, tick streams, order books, and execution logs. Most platforms either oversimplify the interface or present cluttered, illegible layouts that cause severe visual fatigue during extended sessions.

02 // PROJECT GOALS

Maximum Information Depth with Visual Clarity

The goal was to design an ergonomic, modular trading interface that delivers institutional-grade functionality with clean visual hierarchy:

  • High-Density Layouts: Fit critical market indicators on a single screen without sacrificing readability.
  • Subdued Contrast Palette: Use ultra-deep charcoal backgrounds with selective amber/teal highlights to mitigate eye strain.
  • Keyboard-Friendly Order Entry: Design one-click and hotkey-driven trade execution panels.
  • Modular Panel Docking: Establish consistent grid rules for resizable chart and order book modules.
03 // TRADER WORKFLOW ANALYSIS

Analyzing High-Speed Decision Making

Studying trader workflows highlighted that visual focus shifts rapidly between price action, order book depth, and open position risk. Hierarchy must ensure critical status indicators are recognizable in peripheral vision.

  • Color Semantics: Consistent use of green/teal for bids and coral/amber for asks without visual vibration.
  • Monospaced Precision: Tabular numerals across all prices, sizes, and PnL indicators to prevent jumping text.
  • Scannable Order Books: Visual depth bars behind numeric bids and asks for instant liquidity comprehension.
04 // WORKSPACE MODULAR GRID

Structured Multi-Column Layout Architecture

The terminal layout is organized into 3 primary functional zones designed for quick horizontal eye-tracking:

Left Dock

Multi-asset market selector, 24h ticker feed, and watchlist

Center Canvas

Real-time candlestick chart stage with technical overlay toolbar

Right Wing

Order book depth ladder, recent trade prints, and one-click order form
