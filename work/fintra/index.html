01 — UI/UX & PRODUCT CONCEPT PROJECT

Fintra — Banking, simplified.

A modern digital banking interface designed to reduce cognitive friction, improve financial transparency, and streamline everyday money transfers.

ROLE UI/UX Designer
TIMELINE 4 Weeks
DISCIPLINE UI/UX & Design Systems
TOOLS Figma, FigJam, Prototyping
01 // THE PROBLEM

Cluttered Interfaces & High Cognitive Load in Banking

Traditional banking applications often overwhelm users with excessive menus, hidden balances, and multi-layered transfer flows. Everyday tasks—like checking actual spendable funds or initiating a quick peer-to-peer transfer—require navigating through dense, confusing submenus.

02 // PROJECT GOALS

Clarity, Speed, and Reassurance

The primary objective was to rethink digital retail banking by designing an interface that prioritizes speed and mental clarity:

  • Instant Financial Health: Display clear spendable liquidity versus pending expenses at first glance.
  • Frictionless Money Transfers: Reduce the core transfer flow to 3 straightforward steps with clear visual confirmation.
  • Proactive Card Controls: Place card locking, limits, and virtual card generation within instant reach.
  • Accessible Dark Glass Aesthetic: Maintain high contrast and clear visual hierarchy across both desktop and mobile viewports.
03 // RESEARCH & USER PAIN POINTS

Identifying Core User Frustrations

Through comparative analysis of popular retail banking apps and user journey mapping, several critical UX bottlenecks were highlighted:

  • Ambiguous Account Balances: Users struggle to separate posted transactions from authorized holds.
  • Fear of Transfer Errors: Anxiety during recipient selection when account names and numbers lack visual clarity.
  • Hidden Account Security: Inability to quickly freeze a compromised card without digging through settings menus.
  • Complex Charts: Data visualizations that present raw numbers without practical context on monthly spending patterns.
04 // USER FLOW & INFORMATION ARCHITECTURE

A Flattened 3-Pillar Navigation Structure

The application architecture was restructured from a nested 12-page tree into 3 direct primary pillars: Overview, Analytics, and Vaults.

01. Overview

Real-time liquidity, upcoming recurring bills, and instant card toggles

02. Analytics

Category-based cashflow insights, spend trends, and monthly breakdown

03. Vaults

Dedicated savings pockets, automated round-ups, and financial goals

05 // WIREFRAMES & LAYOUT EXPLORATION

Iterating Toward Ergonomic Screen Hierarchy

Low-fidelity wireframing explored various dashboard layouts to optimize the visual balance between account balances, quick-action shortcuts (Transfer, Request, Exchange, Deposit), and recent activity feeds. Testing prioritized card-based grouping over standard tabular lists for faster visual scanning.

06 // DESIGN SYSTEM & TOKENS

High-Contrast Editorial Dark Theme System

A comprehensive design system was constructed in Figma utilizing atomic tokens for typography, spacing, border radii, and color contrast compliant with WCAG accessibility standards.

Obsidian Canvas #0D0E10
Surface Slate #151619
Warm Amber Focus #E8862E
Mint Inflow Accent #2FA79B
Paper Text Primary #EEEAE2
07 // UI DESIGN & PROTOTYPE

Refined Desktop & Mobile Interface

The final high-fidelity design features a unified dark glass aesthetic, custom micro-interactions for transaction pills, an interactive cashflow analytics chart, and a dedicated virtual card manager.

Responsive Web Dashboard (Desktop & Tablet layouts)
Complete Mobile App Design (iOS & Android guidelines)
Interactive Clickable Figma Prototype
Component Token Library & Auto-Layout Specs
08 // PROJECT OUTCOME

Design Summary & Key Takeaways

Fintra demonstrates how structured UX analysis and restrained visual styling can transform complex financial tools into clear, calming, and intuitive digital experiences.
